AI Agents & What They Do

The project?s analysis flow, from city data to forecasts and guidance

01

AQI & Weather Data Agent

Loads current AQI, pollutant measurements, weather conditions, and forecast data from Open-Meteo for the selected city.

02

AQI Prediction Agent

Uses the city?s trained XGBoost models to forecast AQI and PM2.5. It reports no AQI prediction when a compatible model is unavailable.

03

Health Guidance Agent

Summarizes general precautions based on the current AQI category. Its guidance is informational, not a diagnosis.

04

Research Summary Agent

Combines the selected city?s AQI, weather, forecast availability, and model validation details into the dashboard summary and report.

05

AQI & Weather Assistant

Answers questions using the selected city?s current data. It uses local Ollama when available and a built-in response helper otherwise.
